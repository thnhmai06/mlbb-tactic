# I Studied Every Emblem So You Don't Have To
Source: I Studied Every Emblem So You Don't Have To.mp4 | 6:53 | Pick emblem + talents by (role -> sub-type -> stat priority), then apply a short list of per-hero exceptions.

## Summary
- Same items, wrong vs right emblem set = big damage difference; emblem choice can decide kill/escape, gold, and the game [00:00].
- Emblems are NOT one-to-one with the hero's role: a Marksman can use the Assassin or Mage emblem, a Tank can use the Support emblem [00:00-00:30].
- Method: split each role into sub-types (Tank = Supportive vs Damage; Fighter = Sustain vs Damage; Mage = Burst vs DPS; Marksman = Attack Speed / Critical / Burst), state the stats each sub-type must "Maximize", then pick Emblem + Talent 1 + Talent 2 + Core Talent to serve those stats [00:30-01:00].
- Each sub-type then has a short list of exceptions (5 exception screens total) where the emblem is swapped for one hero-specific need (mana, shield sustain, high base damage, multiple builds, magic-damage marksmen).
- Screens are icon-only (no talent captions); talent names come from narration (whisper, may be misheard) cross-checked against icon order. Hero grids on screen are unlabeled portraits.
- Talent names, hero lists and exception heroes are in the LIVE table. Row ids R1-R11 (sets) and E1-E5 (exceptions) are referenced from the tactical section.

## Tactical knowledge

### Core framework
- [00:30] [T] To master emblems, understand WHICH ROLE/SUB-TYPE uses WHICH emblem and talents; do not learn emblems one by one in isolation.
- [00:30] [T] Every set is built from 4 slots: Emblem, Talent 1, Talent 2, Core Talent (column headers on every set screen, from 01:14). Several options may be shown per slot ("X or Y").
- [01:00] [T] Method: (1) identify the hero's role and sub-type, (2) identify the stats that sub-type must maximize, (3) choose the emblem (and talents) that give those stats, (4) check the exception list for the hero.
- [00:00] [T] Emblem choice is not tied to hero class: it follows what the hero needs (damage type, sustain source, mana, base damage), not its class label.
- [00:40] [T] Seven emblem types exist in the video's selector (icon row, left to right): Assassin (purple four-point star), Tank (orange shield), Fighter (red sword), Common (teal sword+shield), Mage (blue staff), Support (green cross), Marksman (gold bow).
- [01:34-05:15] [T] Difficulty bars shown per role: Assassin = Easy (1 of 3), Tank = Medium (2 of 3), Mage = Medium (2 of 3), Support = Easy (1 of 3). Fighter and Marksman bars not seen. Narration: assassin players should "respect" tank players because tanks "don't have it that easy" [01:30].

## Terms & definitions
- "Maximize:" bullet lists on the tree screens = the stat priorities that define each sub-type; emblem/talents are chosen to serve them.
- Emblem Set = Emblem + Talent 1 + Talent 2 + Core Talent.
- Sub-types as used by the video: Tank (Supportive / Damage), Fighter (Sustain / Damage), Mage (Burst / DPS), Marksman (Attack Speed / Critical / Burst), Assassin (one group + critical exception), Support (one group).
- Common emblem = teal sword+shield icon; used as the swap when mana is the issue.
- "Hybrid regen" = narration reason for the Common emblem on the high-mana mage.
