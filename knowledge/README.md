# knowledge/ reading guide
Purpose: durable tactical foundations extracted from 16 tactics videos, written so they hold in any game of the same genre.

Rules that every file follows:
1. Tactics state properties and principles only: no hero, item, spell, talent, objective or UI names; no item/hero stats. Roles and archetypes (tank, burst mage, marksman, initiator...) and generic objects (tower, minion, early/major objective, jungle) are used.
2. Anything volatile (timers, economy numbers, effect values, which function categories exist, setting names) sits in the LIVE table at the end of each file and in `00-live-data-reconcile.md`, to be re-checked at use time.
3. Game-specific names are mapped once, in the "Term mapping" table of `00-live-data-reconcile.md`.
4. Every rule keeps its source (`src: <video> mm:ss`) so the original wording can be recovered from `work/notes/`.
5. `⚠ conflict` / `⚠ unverified` flags mark open questions carried over from the notes.
