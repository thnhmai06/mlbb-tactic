# knowledge/ reading guide
Purpose: durable tactical foundations extracted from 16 MLBB tactics videos.

Rules every file follows:
1. Tactics state properties and principles. MLBB mechanic terms (Turtle, Lord, Retribution, plating, crab, inhibitor, buffs, emblem system...) are KEPT with their definitions (see `00-live-data-reconcile.md`).
2. No hero, item or talent names, and no stats of heroes or items: only the property/function (e.g. "an item that reduces the attacker's attack speed").
3. Volatile numbers (timers, economy, thresholds, effect values) and the existence of function categories sit in the LIVE table at the end of each file and in `00-live-data-reconcile.md`, to be re-checked at use time.
4. Every rule keeps its source (`src: <video> mm:ss`) so the original wording can be recovered from `work/notes/`.
5. `⚠ conflict` / `⚠ unverified` flags mark open questions carried over from the notes.
